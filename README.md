# Hacker News Job Board in React

This React app pulls in jobs via the [Hacker News Jobs API](https://github.com/HackerNews/API) using:

- React
- pnpm
- TanStack Query (<code>useInfiniteQuery</code> hook)
- Accessibility testing on [VoiceOver screen reader](https://en.wikipedia.org/wiki/VoiceOver) for Mac on Safari browser
